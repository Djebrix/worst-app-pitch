> PebblePal: an app that scans your driveway pebbles, assigns each one a personality, and sends a daily mood report on which pebble is thriving and which one needs space, for homeowners who refuse to let a single stone go unmonitored.

A one-sentence pitch for the worst, most useless app imaginable — entered in
[The Worst App Idea Ever Pitched](https://make.fun/bounty/u-plucky-sparrow-67-the-worst-app-idea-ever-pitched-a0396b23)
on make.fun.

## How it works

`main.py` (Python standard library only, no network, deterministic) writes the
pitch above to `entry.txt` inside `$ENTRY_OUTPUT_DIR` (default `/output`).

```sh
python3 main.py
```
